LineCheck 安装与使用指南

逐行阅读网页，标记已复查文字，把需要再看的内容留待复查。

安装 · 快捷键 · 阅读流程 · 问题排查

从 Chrome 应用商店安装

  1. 在桌面版 Chrome 中打开官方 LineCheck 商店页面。
  2. 选择添加至 Chrome，查看扩展所需权限并安装。
  3. 打开或刷新普通文章网页，点击 LineCheck 图标并开启 Focus。

另一种方式：从开源代码安装

LineCheck 免费、开源。请使用桌面版 Chrome 120 或更高版本。

  1. 打开 LineCheck 源码仓库，选择 Code → Download ZIP，然后解压。
  2. 在 Chrome 地址栏输入 chrome://extensions，开启开发者模式。
  3. 选择加载已解压的扩展程序，打开包含 manifest.json 的 linecheck-extension 文件夹。
  4. 打开或刷新普通文章网页，点击 LineCheck 扩展图标并开启 Focus。

请保留解压后的源码文件夹。更新源码后，需要重新加载扩展并刷新文章。可以在扩展弹窗中选择界面语言。

键盘快捷键

聚焦状态下的键盘操作
按键作用
↑ / ↓切换到上一行或下一行，不添加标记
Enter切换绿色已复查标记，停留在当前行
F切换红色待复查标记，停留在当前行
← / →缩小或放大当前行文字
Esc退出聚焦并保留标记

重复使用同一种标记会清除它；使用另一种标记会替换颜色。标记后不会自动跳到下一行。

全局聚焦快捷键可在 chrome://extensions/shortcuts 中设置。不同扩展版本或 Chrome 设置下的快捷键可能不同；如果与浏览器或其他扩展冲突，请更换按键组合。

一个简单的阅读与复查流程

  1. 开启 Focus，阅读清晰的当前行，用方向键按自己的节奏移动。
  2. 完成复查后按 Enter；遇到需要再看的文字时按 F。
  3. 用左右方向键调整当前行的放大程度，不改变原文章排版。
  4. 结束后按 Esc，保留文字标记。再次打开同一完整网址时，扩展会尝试恢复记录。

阅读记录仅保存在当前浏览器配置的本地存储中，不会跨设备同步。扩展不提供自动拼写或语法检查。

常见问题排查

无法开启聚焦

安装后请刷新文章。Chrome 内部页面、Chrome 应用商店和内置 PDF 阅读器不支持此阅读工具，请尝试普通 HTML 文章。

有些文字被跳过

图片文字、画布、嵌入式框架和 Shadow DOM 不受支持。复杂排版或动态变化的页面可能无法稳定工作。

之前的高亮没有恢复

请确认完整网址一致，包括查询参数和片段。恢复需要唯一匹配的文字锚点；文章修改或重复文字可能导致恢复失败。

能阅读本地 HTML 文件吗？

在 Chrome 的扩展详情中开启允许访问文件网址。本地 PDF 仍不受支持。

如何删除记录？

扩展弹窗的清除操作会移除当前页的标记和已保存阅读位置，部分页面元数据仍会保留。卸载扩展会清除扩展本地存储，但不会删除另行导出的文件。完整说明见隐私政策（英文）。
