记录保存在本地

阅读位置和文字标记保存在浏览器扩展的本地存储中。没有分析统计，也不向开发者上传阅读记录。

如何使用 LineCheck 阅读网页

  1. 安装扩展，在桌面版 Chrome 中打开普通文章网页。
  2. 点击扩展图标，开启 Focus。
  3. 使用 ↑、↓ 切换行，Enter 标记已复查，F 标记待复查。
  4. 按 Esc 退出聚焦，保留文字标记。

用于长文阅读、学习与人工校对

阅读长文章时保持当前位置，学习时标记已复查的内容，校对时标出需要再斟酌的文字。由你决定标记哪些内容；LineCheck 不会自动纠正拼写或语法。

常见问题

支持 PDF 吗？

不支持。它面向普通横排 HTML 网页文字，不适用于浏览器内置 PDF 阅读器、浏览器内部页面、图片文字、嵌入式框架及部分复杂排版。

会上传我的阅读历史吗？

扩展在本地处理文字，不向开发者发送阅读记录。本地记录可能包括完整网址、标题、标记文字及阅读位置。详情见隐私政策（英文）。

下次打开还能看到高亮吗？

LineCheck 会通过文字锚点，尝试在同一完整网址恢复标记。文章变化或存在无法唯一匹配的文字时，恢复可能失败。

支持哪些界面语言？

Chrome 应用商店版本支持英语、德语、简体中文、日语和韩语。此网站也提供英文版本。

如何安装？

在 Chrome 120 或更高版本中，按照Chrome 应用商店安装指南操作即可，也支持从源码安装，无需 LineCheck 账号。
