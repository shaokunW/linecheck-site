Move up and down with the keyboard. Magnify the current line without changing the original article layout.

Highlight and review

Mark reviewed text green and flag passages red for another look. Repeat the same action to clear a mark.

Keep records local

Reading position and text marks stay in the extension’s local browser storage. No analytics or developer upload.

How to read with LineCheck

  1. Install LineCheck and open an ordinary article webpage in desktop Chrome.
  2. Click the extension icon and start Focus.
  3. Use ↑ and ↓ to move, Enter to mark, and F to flag.
  4. Press Esc to close Focus and leave your marks visible.

See installation, all keyboard controls, and troubleshooting.

For articles, study, and manual proofreading

Use the line guide to keep your place in long articles, mark study passages you have reviewed, or flag wording to revisit while proofreading. You decide what to mark; LineCheck does not automatically correct spelling or grammar.

Frequently asked questions

Does LineCheck work with PDFs?

No. It is intended for ordinary horizontal HTML text. Built-in PDF viewers, browser pages, image text, embedded frames, and some complex layouts are unsupported.

Does it send my reading history anywhere?

The extension processes text locally and does not send reading records to the developer. Saved records can include full page URLs, titles, marked text, and reading position. See the privacy policy for details.

Can I return to my highlights?

LineCheck attempts to restore marks on the same full URL using saved text anchors. Changed or ambiguous text may prevent restoration.

Which languages are supported?

The Chrome Web Store version supports English, German, Simplified Chinese, Japanese, and Korean interfaces. This website has 简体中文介绍和指南.

How do I install it?

Follow the Chrome Web Store installation instructions for Chrome 120 or later. Source installation is also available. They do not require a LineCheck account.
